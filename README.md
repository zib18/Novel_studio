# Novel Studio

Личная студия для написания длинных веб-новелл. Основной язык — русский.

## Текущее состояние

Добавлена стартовая структура FastAPI-сервера и маршрут `GET /api/health`.
Значение `stage: bootstrap` означает только запуск API.

База данных, авторизация, редактор глав, канон, очередь задач, агенты,
синхронизация, PWA и APK ещё не реализованы. Наличие библиотек в
`requirements.txt` не означает готовность этих функций.

## Запуск на Windows

Нужен Python 3.12. Скачайте исходники через GitHub → Code → Download ZIP,
распакуйте архив и откройте PowerShell в корне проекта, где находится `backend`.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000/api/health.
Документация API доступна по адресу http://127.0.0.1:8000/docs.
Для остановки сервера нажмите Ctrl+C в его терминале.

Ожидаемый ответ:

```json
{
  "status": "ok",
  "service": "Novel Studio",
  "version": "0.1.0",
  "stage": "bootstrap"
}
```

## Проверки

GitHub Actions проверяет блок на Ubuntu и Windows с Python 3.12:
установку всех зависимостей, `pip check`, синтаксис, импорт библиотек,
действие `.gitignore` и настоящий HTTP-запрос к запущенному Uvicorn.

После установки зависимостей проверку сервера можно выполнить локально:

```powershell
.\.venv\Scripts\python.exe backend\scripts\verify_bootstrap.py
```

При скачивании ZIP нет истории Git, поэтому проверка правил Git пропускается;
запуск сервера проверяется. В Git-клоне выполняются обе проверки.

Проверка запуска не проверяет базу данных, качество прозы или ИИ-цепочку.
В `requirements.txt` зафиксированы проверенные версии основных зависимостей.
Полный список установленных пакетов сохраняется в артефактах успешного CI.
Транзитивные зависимости пока не закреплены отдельным lock-файлом.
