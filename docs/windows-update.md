# Обновление Windows без потери романов

Обновление добавляет корзину романов и отдельных неутверждённых идей.
Утверждённые факты и журнал запретов защищены от удаления как обычные идеи.

1. В открытой студии дождитесь сохранения правок на сервере. Закройте остальные вкладки студии.
2. В двух окнах PowerShell, где работают сервер и обработчик ИИ, нажмите **Ctrl+C**.
3. Скачайте [ZIP обновления](https://github.com/zib18/Novel_studio/archive/refs/heads/novel-studio/windows-update.zip).
4. Нажмите правой кнопкой по ZIP → **Извлечь всё**. Распакуйте в новую отдельную папку.
   Прежнюю папку программы не удаляйте и не переносите внутрь новой.
5. В распакованной папке откройте **Update-Windows.cmd** двойным щелчком.
6. Когда появится запрос пути, вставьте путь **прежней** установленной папки и нажмите Enter.
   Например: C:\Users\Samal\Desktop\Novel_studio-novel-studio-core.
   Нужна папка, где находятся backend, frontend и .venv.
7. Дождитесь сообщения **«Готово. Данные, ключ и учётная запись сохранены»**.
   Установка зависимостей может занять несколько минут. Не закрывайте окно.
8. Откройте PowerShell в **прежней** папке и запустите сервер:

~~~powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
~~~

Во втором PowerShell из той же папки запустите обработчик:

~~~powershell
Push-Location backend
..\.venv\Scripts\python.exe -m app.generation.worker
~~~

Откройте прежний адрес http://127.0.0.1:8000.
Если страница была открыта, обновите её. Не очищайте данные браузера:
там могут оставаться локальные черновики.

## Что сохраняется

Помощник использует прежний Python из .venv, создаёт резервную копию SQLite
в backend/data/backups/before-update-…db, собирает интерфейс, обновляет исходники
и применяет миграцию. Он не заменяет backend/.env, backend/data и .venv.
Учётная запись и пароль сохраняются. Новый пользователь не нужен.

Если резервную копию или интерфейс подготовить не удалось, исходники прежней
программы не копируются. Если ошибка возникла позже, не удаляйте прежнюю папку:
сохраните сообщение об ошибке и копию базы. Сетевой доступ нужен для npm/pip.
Для PostgreSQL этот помощник останавливается на резервном копировании;
обновление серверной базы требует отдельного pg_dump.

Если файл .cmd не открывается, откройте PowerShell в новой распакованной папке:

~~~powershell
py -3.12 tools\update_windows.py
~~~

## Как удалять

- В библиотеке под романом нажмите **Удалить роман**, затем **Переместить в корзину**.
- В разделе **Библия романа → Идеи** у записи нажмите **Удалить идею** и подтвердите.
- Для восстановления откройте **Корзина** в библиотеке или **Корзина идей** в библии.

Восстановление возвращает прежние главы, редакции и статусы.
Идея после восстановления остаётся идеей; она не становится каноном.

При несинхронизированных правках удаление романа блокируется с кнопкой
перехода к соответствующей главе. Локальные черновики не стираются.
Без подключения удаление и восстановление недоступны.

Удаление и восстановление меняют версию контекста и отменяют связанные
незавершённые задачи ИИ. Старые задачи после восстановления не запускаются сами.
Уже отправленный платный запрос может завершиться и иметь расход;
его поздний результат не заменит главу или решение автора.

Это корзина без автоматической очистки. Физическое безвозвратное стирание
в этом обновлении не предусмотрено.
